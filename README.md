A comprehensive exploratory data analysis of over 64,000 video game records from Kaggle. This project uncovers trends in global sales, regional preferences, platform performance, genre popularity over time, and the relationship between critic scores and commercial success.

## 📁 Dataset

The dataset (`vgchartz-2024.csv`) contains video game sales data with the following key columns:
- `title`, `console`, `genre`, `publisher`
- `release_date`, `critic_score`
- `total_sales` (global in millions)
- Regional sales: `na_sales`, `pal_sales`, `jp_sales`, `other_sales`

*Source: https://www.kaggle.com/datasets/siddharth0935/video-game-sales

## 🛠️ Technologies Used

- **Python** – core programming language
- **pandas** – data manipulation & aggregation
- **matplotlib & seaborn** – data visualization
- **numpy** – numerical operations
